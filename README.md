# SUT Navigator

A web app that helps students and visitors find their way around Suranaree University of Technology: a campus map with category pins, plus search down to the room.

**UI prototype (web, mock data):** https://chatthadasainoi-cmyk.github.io/portfolio/demo/sut-navigator/

Team project, Object-Oriented Programming course (Jan 2026).

![Campus map](https://chatthadasainoi-cmyk.github.io/portfolio/img/nav-map.jpg)

## Features
- **Campus map:** pins for teaching buildings, food, dorms and services; recommended places
- **Search:** buildings and rooms, with category filters
- **Room list:** every building and the rooms inside it
- **Report:** top 5 most-viewed places and visits per category
- **Accounts:** sign-up, sign-in, password reset and guest mode; admin dashboard and room management

## Tech stack
JavaScript · HTML · Tailwind CSS

## Run locally
Open `SUT_NAVIGATOR_FINAL.html` in a browser.
